# Netflix Landing Page

A Netflix-inspired landing page built using HTML and CSS to practice frontend web development. The project focuses on recreating the visual layout, navigation, hero section, content sections, and overall design of a modern streaming platform.

## Features

- Netflix-inspired user interface
- Responsive webpage layout
- Navigation bar
- Hero/banner section
- Call-to-action buttons
- Movie/content sections
- Custom CSS styling
- Clean and organized layout

## Technologies Used

- **HTML5** – Structure and content
- **CSS3** – Styling and layout

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/vivekrahangdale07/Netflix-Landing-Page-.git
```

2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation or dependencies are required.
