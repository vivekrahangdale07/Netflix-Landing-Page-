# Netflix-Landing-Page-
A responsive Netflix-inspired landing page built to practice frontend web development using HTML and CSS. The project focuses on recreating the visual structure, layout, typography, and overall user interface of a modern streaming platform.

Features
Netflix-inspired landing page design
Responsive layout
Hero section with call-to-action
Navigation bar
Movie/content sections
Clean and structured UI
Custom styling using CSS
Technologies Used
HTML5
CSS3
